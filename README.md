# 🕷️ Spider-Man Themed Developer Portfolio

> **"With great code comes great responsibility."**  
> A high-performance, tactile developer portfolio inspired by Spider-Man lore and modern design engineering. Built with React 19, TypeScript, Tailwind CSS, Framer Motion, and Web Audio API.

---

## ⚡ Highlights & Superpowers

- **🕸️ Interactive Spider-Web Physics**: Dynamic HTML5 Canvas background where web strands connect between particles and stretch elastically to your mouse cursor.
- **🎨 Multiverse Spider-Suit Switcher**:
  - **Peter Parker (Classic)**: Crimson Red & Electric Blue on midnight dark.
  - **Miles Morales (Spider-Verse)**: Neon Crimson & Cyber Yellow with glitch aesthetic.
  - **Miguel O'Hara (Spider-Man 2099)**: Cyberpunk Cyan & Purple Neon.
- **🔊 Tactile Web Audio SFX**: Real-time synthesized audio effects using the Web Audio API (web-shooting *thwip*, spider-sense tingling chime, and tactile clicks) — zero external sound files required!
- **🚨 Interactive Spider-Sense Alert**: Comic-style radiating lightning arcs and responsive alert banners.
- **🛹 Dynamic Hanging Spider Mascot**: Physical spring-physics upside-down swinging Spider-Man.
- **📁 Classified Mission Files**: Showcase of shipped projects (Solana Scrub Chart, 3D Skeuomorphic Credit Card, Card Pieces Swipe Deck, Swipe Action Row, Zerodha Trading Terminal UI) with live interactive specimen previews.
- **📡 Spider-Signal Comm Terminal**: 1-click email copy with web confetti explosion and direct encrypted transmission terminal.

## 🚀 Getting Started

### Prerequisites

- Node.js (v18+)
- npm or pnpm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/alqamarzz/spiderman-portfolio.git

# Navigate to project folder
cd spiderman-portfolio

# Install dependencies
npm install

# Start local dev server
npm run dev
```

Visit `http://localhost:5173` in your browser.

### Building for Production

```bash
npm run build
```

The production assets will be output in the `dist/` directory, ready to deploy to GitHub Pages, Vercel, or Netlify.
